# Public-setting partial-feedback formalization

Status: 2026-10-31. This README distinguishes checked theorem statements from
remaining integration work. A green Lean build, a green Rocq build, and a
solution of the original open learning-theory problem are three different
claims.

## Research target

Shao, Fang, Lin, and Tao, *Partial Feedback Online Learning*,
arXiv:2601.21462v3, ask in the final part of Section 3.3 whether randomized
and deterministic learners can have different learnability in the public
partial-feedback setting. The paper separately studies finite-Helly /
nested-inclusion sufficient conditions in Section 3.2 and oblivious-versus-
public separations elsewhere. Those questions must not be conflated.

The candidate in this repository uses the first uncountable ordinal
\(\omega_1\), its countable-cocountable sigma algebra, and the 0–1
probability measure. The measurable space is deliberately non-standard-Borel
and is not generated by a countable family.

## Candidate construction

- Labels: \(Y=\omega_1\).
- Measurable sets: countable or cocountable subsets of \(Y\).
- Probability: \(\mu(A)=0\) for countable \(A\), and \(\mu(A)=1\) for
  cocountable \(A\).
- Acceptable sets: upper tails \(S_\beta=\{y:\beta\le y\}\).
- Contexts: \(X=\mathbb N\).
- Hypotheses: \(H=Y^{\mathbb N}\), with one global hypothesis required
  to realize all context/acceptable-set pairs.

Every strict initial segment below an ordinal \(w<\omega_1\) is countable.
Hence each upper tail has measure one and its complement has measure zero.
The countable-cocountable 0–1 measure is countably additive: a disjoint
measurable sequence has at most one cocountable member; if none exists, the
union is countable, and if one exists, the union is cocountable.

### Randomized side

For a visible witness \(w_t\) fixed before the current sample, every
compatible upper-tail threshold \(\beta_t\) satisfies \(\beta_t\le w_t\).
A mistake implies
\[
  \hat y_t < \beta_t \le w_t.
\]
Thus the miss section is contained in the countable initial segment below
\(w_t\), which has probability zero.

The original Lean module PublicSetting/Lean/OmegaOneSeparation.lean
formalizes the countable-cocountable measurable space and measure, the
upper-tail facts, uniform one-round miss-set nullity, full-path miss
containment for a fixed finite witness sequence and arbitrary terminal
thresholds depending on the sampled path, and the deterministic comparison
construction. These results use the paper's abstract measurable-space model.

### Deterministic side

For a deterministic path of predictions \(p_t\), the public adversary
reveals \(w_t=p_t+1\). One global target family is
\[
  H^*=\{f:\mathbb N\to\omega_1:\forall t,\ p_t+1\le f(t)\}.
\]
It is nonempty and its projection at context \(t\) is exactly
\(S_{p_t+1}\). The same global family therefore realizes all acceptable
sets, contains every visible witness, and excludes every deterministic
prediction. The comparator has zero loss and the deterministic learner
makes exactly \(T\) mistakes.

### Relation to Theorem 15

Every countable sequence of upper-tail thresholds has supremum below
\(\omega_1\). Thus every countable subfamily of upper tails has nonempty
intersection, while the intersection of all upper tails is empty. This
family does not satisfy Theorem 15's countable-decreasing-empty-intersection
condition; its Helly number is infinite. Pairwise nestedness alone is not
the same as that theorem's explicit countable condition.

## Added formalization: the complete sequential process and tower property

PublicSetting/Lean/SequentialKernelMinimax.lean now includes:

- strategyDependentPathMeasure: for every strategy pair \((x,y)\), a
  separate sequence \(\kappa_{x,y,n}\) of Markov kernels is used. Each
  transition takes the complete realized prefix as its input, not merely
  the current state.
- strategyDependentPathMeasure_isProbability: the induced Ionescu–Tulcea
  trajectory is a probability measure for each fixed strategy pair.
- strategyDependent_trajectory_tower: the conditional-expectation tower
  identity is applied to the full path law for every fixed strategy pair,
  under the explicit integrability assumption.
- finitePrefix_consistency: a wrapper for Mathlib's
  Kernel.traj_comp_partialTraj.
- trajectory_tower: a wrapper for Mathlib's Kernel.condExp_traj.

The tower theorem is an almost-everywhere identity under the appropriate
path law. It does not make an arbitrary nonmeasurable pathwise loss
measurable, and it does not assert pointwise equality at null histories.

SequentialKernelGame now indexes transition kernels by the strategy pair
and round. sequential_kernel_minimax applies Sion's minimax theorem to a
compact-convex strategy interface, but its semicontinuity, quasi-convexity,
quasi-concavity, and real-extremum assumptions are explicit inputs. Kernel
measurability alone does not imply them.

## Added formalization: Appendix G equations (24)–(26)

PublicSetting/Lean/AppendixGBackwardInduction.lean declares the finite-horizon
public and oblivious value recursions. A randomized move is an actual
probability measure on labels. Each stage maximizes over admissible sets
whose extension is globally realizable.

The concrete state is PairHistory X Y := List (X × Set Y). The predicate
pairHistoryGloballyRealizable requires one and the same hypothesis
\(f\in H\) to satisfy every historical condition \(f(x_i)\in S_i\).
The lemma pairHistoryGloballyRealizable_extend_iff proves that a new pair
is feasible exactly when one hypothesis realizes all old pairs and the new
one.

The machine-checked induction theorem publicValue_eq_obliviousValue shows
that the public continuation value is independent of the realized
sampled-label list under this information structure. The file further states:

- appendixG_pairHistory_value_identity: equality for the paper's
  globally set-realizable pair-history predicate;
- appendixG_public_eq_oblivious_minimax: equality of the finite-horizon
  initial public and oblivious values, corresponding to equations (24)–(25);
- appendixG_equation_26: accumulated past loss plus public continuation
  equals accumulated past loss plus oblivious continuation, the form of
  equation (26).

This is a finite-horizon result for Appendix G / Theorem 18's information
structure. The next public pair update depends on the current context and
acceptable set, not on the just-drawn current label. A different adversary
whose hidden acceptable-set choice depends on that fresh sample is outside
this theorem.

## Rocq: concrete \(\omega_1\) and the PRNG boundary

Rocq/ConcreteOmegaOne.v imports Gaia 2.4 and defines
omegaOne := Ordinals1.aleph_one, concretely cnext omega0. The adapter
states / proves:

- omegaOne_iff_countable_ordinal, using Gaia's aleph_oneP;
- omegaOne_countable_sup, closure of countable ordinals under countable
  suprema;
- omegaOne_not_countable, using Gaia's Cantor_Omega cardinality result.

Gaia's foundational assumptions are not bare constructive CIC: its
Bourbaki-style set theory uses classical and set-theoretic principles. The
adapter emits Print Assumptions output. It constructs a concrete set
representing \(\omega_1\), but the generic countable-ideal game development
in Rocq/OmegaOneSeparation.v has not yet been instantiated over that Gaia
carrier. Do not describe the Rocq game proof as a concrete \(\omega_1\)
instance.

Rocq/PRNGNoGo.v formalizes the obstruction for any countably enumerable
seed space: its deterministic sampler has countable output range \(R\);
the target measure assigns \(\mu(R)=0\), while the push-forward of any
source probability assigns mass one to \(R\). The total-variation distance
is therefore one. This rules out finite-state PRNGs and terminating
countable-output implementations as exact samplers for the target measure.
It is a proof of impossibility, not an executable replacement.

For an ideal Lebesgue-uniform real source, an exact measurable push-forward
onto the countable-cocountable \(\omega_1\) law exists iff
\(\operatorname{cov}(\mathcal N)\le\aleph_1\). CH suffices; models with
\(\operatorname{cov}(\mathcal N)>\aleph_1\) preclude it. This is a
set-theoretic existence criterion for an ideal uncountable real source, not
an ordinary finite-bit PRNG. Details are in RNG_COMPATIBILITY.md.

## Explicit remaining boundaries

1. The Gaia ordinal adapter is not yet connected to the generic Rocq
   CountableIdeal, countable-cocountable measure, and full game development.
2. The general Lean trajectory/tower theorem assumes the relevant path
   reward is measurable and integrable. For the countable-cocountable
   \(\omega_1\) sigma algebra, sectionwise nullity does not imply product
   measurability. In particular,
   \(\{(\alpha,\beta):\beta\le\alpha\}\) is not in the product sigma
   algebra, even though each vertical section is countable. The unrestricted
   adaptive full-path risk cannot be fed into the ordinary tower theorem
   without an additional joint-measurability hypothesis or a different
   iterated-risk semantics.
3. The Sion minimax interface is general but requires compactness, convexity,
   semicontinuity, quasi-convexity/quasi-concavity, and real extrema to be
   proved for a concrete game. The Appendix G finite-horizon recursion is
   formalized separately; a full identification of every strategy space and
   payoff regularity hypothesis in the original public protocol remains.
4. This formalization does not claim that the original public
   randomized-versus-deterministic learnability open question has been
   definitively solved in every standard-Borel or algorithmically samplable
   model.

These are mathematical/model boundaries, not missing sorry placeholders
or compiler errors in the statements that are actually present.

## Repository and tool responsibilities

| Resource | Assigned role | Boundary |
|---|---|---|
| Mathlib4 | Trusted Lean measure, kernel, trajectory, conditional-expectation, and Sion library | Does not prove application-specific hypotheses automatically |
| Gaia 2.4 | Concrete set-theoretic ordinals and aleph_one for Rocq | Classical set-theoretic foundation; project game instance still separate |
| LeanDojo-v2 | Lean repository tracing, theorem retrieval, proof-search assistance | Suggestions must be checked by Lean; optional GPU/API workflows are not used in CI |
| Naproche | Structured natural-language proof checking and exposition audit | Not a replacement for Lean/Rocq |
| cvc5 | Finite SMT counterexample and arithmetic-side-condition search | Not an uncountability or measure-theory proof engine |
| SageMath / SymPy / Wolfram | Exact finite examples and symbolic sanity checks | Not trusted proof kernels |
| GAP | Finite group actions and symmetry/orbit reduction where relevant | Low direct relevance to the current ordinal-measure proof |
| Macaulay2 | Commutative algebra / polynomial-ideal checks if an algebraic finite model arises | No direct role in the measure construction |
| Context7 | Current library/API documentation | Documentation only |
| Parallel Search / Sider Scholar | Source-paper and literature retrieval | Literature evidence, not formal verification |
| GitHub Actions | Version-pinned Lean/Rocq compilation | Evidence applies to the exact source commit and run |

All auxiliary repositories are free/open-source projects, but they are not all
build dependencies: adding irrelevant packages would enlarge the trusted
surface without strengthening the proof.

## Verification

Pinned workflow versions: Lean 4.35.0 / Mathlib 4.35.0 and Rocq 9.2.0 with
Gaia 2.4. From the repository root:

~~~sh
cd PublicSetting/Lean && lake build
~~~

The Rocq workflow uses the official rocq/rocq-prover:9.2.0 container.
For a local reproduction, first install the pinned Gaia ordinal package in
the active OPAM switch:

~~~sh
opam install coq-gaia-ordinals.2.4
eval "$(opam env)"
~~~

Then compile the Rocq modules in dependency order, followed by the root
Rocq/VCLearning.v.
