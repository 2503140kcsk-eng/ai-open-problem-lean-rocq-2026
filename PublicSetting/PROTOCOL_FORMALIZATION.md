# Public-setting protocol formalization: status and limits

## Primary source

Shao, Fang, Lin, and Tao, *Partial Feedback Online Learning*, arXiv:2601.21462v3 (revised 2 April 2026):
- https://arxiv.org/html/2601.21462v3
- https://arxiv.org/abs/2601.21462

Section 1.1 introduces partial feedback and set-realizability. Section 3.3 defines the public-versus-oblivious adversary distinction; Section 3.2 contains Theorem 15 and the inseparability necessity question. The finite-Helly / nested-inclusion necessity question appears at the end of Section 3.2. Section 3.3 separately defines the oblivious-versus-public distinction. For the public partial-feedback protocol, the current round's order is:

1. the adversary chooses the instance/context;
2. the learner chooses a distribution/action using its observable feedback history;
3. the adversary reveals one acceptable witness, with access to the current distribution but not the current draw;
4. the current prediction is sampled;
5. the completed draw is available to the public adversary in subsequent rounds;
6. after the path is realized, evaluation requires one global target subfamily F* whose image at each context gives the acceptable-label set.

For one fixed F*, the accepted labels at x are exactly {f(x) | f in F*}. Choosing unrelated sets or unrelated target subfamilies at different rounds does not satisfy set-realizability.

## What has been formalized

The Lean and Rocq files give the learner access to its own previously sampled predictions as well as the public transcript; neither the learner nor the adversary receives the hidden acceptable sets or correctness bits during play. The public adversary can inspect completed previous draws, but its current witness function has no argument for the current draw. A one-round transition computes context, learner action, witness, and then draw in this order.

They also formalize the global accepted-label predicate generated by a single F. As a proved boundary case, for an infinite label set and a sequence of predictions, the complement-family target can accept every witness that differs from its corresponding prediction while excluding every prediction. For the bounded-support sampler submodel, the adversary chooses a label outside the support before the sample; after the whole sample path, one global complement-family target realizes all witnesses and makes all predictions incorrect.

The Lean module defines `NatSubprobability` using rational atom masses and a finite-prefix mass bound; it machine-checks `prefix_scaled_gt` and `exists_low_mass_label`. The Rocq module separately machine-checks `prefix_scaled_gt_nat` and `exists_scaled_low_mass_nat` using integer-scaled masses. These establish corresponding low-mass atom bounds in both provers, but the subsequent conditional-expectation argument for this arbitrary subprobability model remains unformalized.

Separately, `AdaptiveMoments.lean` and `AdaptiveMoments.v` now formalize a concrete finite sequential-uniform sampler. Lean proves that the length-T path space has exactly T! equiprobable paths, that the rational exponential match moment is at most T+1, and that a fixed predictable target's tail probability satisfies 2^K P(M >= K) <= T+1. Lean also proves the finite-candidate union budget as a rational inequality; Rocq 9.2 independently proves the corresponding integer-scaled tail and candidate-aggregation bounds. This gives a machine-checked moment-to-tail bridge for that explicit sampler, but it is not yet linked to the full public-game minimax-regret theorem or to the arbitrary `NatSubprobability` construction.

The bounded-support result is now stated as an explicit pathwise loss gap in both provers: the sampled path loses exactly T rounds against the global target, while the visible-witness path is a comparator with zero loss. This is a rigorous adversarial lower bound for the restricted model where every round's sampling distribution has finite support on the natural labels. It does not establish a randomized o(T) upper bound; indeed, it shows that this restricted model is too weak to demonstrate the desired separation.

## The unresolved theorem

The final paragraph of Section 3.3 asks whether randomized and deterministic learners can have distinct learnability in the public partial-feedback setting; this is the target of this formalization. A separate question at the end of Section 3.2 asks whether the finite-Helly or nested-inclusion criterion is necessary for inseparability. Section 3.3 also proves a distinct comparison between oblivious and public adversaries. The paper's Theorem 18 is that oblivious-versus-public separation, not the target question. These must not be conflated.

A fresh search on 29 October 2026 did not find a later work resolving this exact question. This bounded search is not a proof that no resolution exists.

Accordingly, this repository deliberately does not contain an alleged proof of the randomized upper bound. No axiom, placeholder proof, or admitted theorem is used to claim the open problem is solved.

## General pathwise terminal-target lemma

The protocol sources also define a terminal exclusion path from any pair of realized predictions and pre-draw visible witnesses: exclude the prediction when it differs from the witness; on a collision, exclude a different label. Both proof assistants establish that one global family of all functions avoiding that exclusion sequence accepts every visible witness, and that its pathwise loss equals the number of prediction/witness mismatches (the comparator witness path has zero loss). This applies to the full product class, not only bounded-support samplers. It is a *negative boundary result*: a randomized upper bound must rely on structural restrictions on the hypothesis class; the lemma does not supply that upper bound.


## Omega-one candidate (added 31 October 2026)

The new candidate uses the full label space omega_1 and the prescribed family of upper tails S_beta={y: beta<=y}, with the countable-cocountable sigma algebra and its 0/1 probability measure. This is distinct from the bounded-support natural-label construction above.

For a fixed public witness w, every possible terminal upper tail compatible with that witness has threshold beta<=w. A mistake is therefore confined to the countable initial segment below w, independently of whether the terminal global target family is chosen after the current or complete prediction path. The countable-cocountable measure assigns that event probability zero.

Conversely, for any deterministic path p_t, the public adversary can reveal p_t+1 and use one global target family consisting of all functions f with f(t)>=p_t+1 for every t. The coordinate image of that same family is exactly the tail S_(p_t+1), so every deterministic prediction is wrong on every round.

Theorem 15's structural criterion does not cover this family: every countable sequence of upper tails has nonempty intersection by countable boundedness of omega_1, while the intersection of all upper tails is empty.

### Verification caveat

The Lean file PublicSetting/Lean/OmegaOneSeparation.lean is the concrete omega_1 development. The Rocq file PublicSetting/Rocq/OmegaOneSeparation.v is an independent generic theorem over an ordered type and a countable ideal with the omega-one properties; it does not construct the concrete ordinal type omega_1 in Rocq Stdlib. Both Lean and Rocq jobs passed on code commit 1168ded2065bc238a1f6978b5b48addfece2dee3 (run 41157208222). The later public-history refinement is being checked separately. Rocq remains an abstract ordered-type development, not a concrete omega_1 instantiation.

The random upper-bound uses the paper's broad measurable-space model (arbitrary sigma algebra and probability measures). It is not a standard-Borel or usual-PRNG construction. Thus, if the intended setting imposes a standard Borel label space or ordinary algorithmically samplable randomness, the question is not settled by this candidate.

The proof also still needs a single top-level public-game theorem that packages the conditional one-round zero-error lemma and the pathwise deterministic lower bound into the exact minimax regret semantics of the paper. This remains a required verification step.

## Public-history strategy input

The Lean strategy interface now records a list of public round triples (context, visible label, realized prediction). This is intentionally more expressive than a history of only contexts and visible labels: previous realized predictions are visible in the public setting. The current-round learner action is computed from the previous history, after which the adversary chooses the visible label.


## Target open question and formal status (2026-10-31)

The exact target is the final paragraph of Section 3.3 in Shao–Fang–Lin–Tao, arXiv:2601.21462v3: whether randomized and deterministic learners can have distinct learnability in the public partial-feedback setting. The separate end-of-Section-3.2 question about necessity of finite Helly number / nested inclusion must not be substituted for it.

Lean's omega-one file now includes a full sampled-path miss-event containment theorem: for arbitrary path-dependent terminal upper-tail thresholds that all contain the pre-sampling witnesses, any error path lies in the finite union of coordinate initial-segment cylinders. Rocq proves the abstract order/ideal counterpart. The finite-product measure calculation converting this containment into a joint probability-zero theorem is not separately formalized. The literal Appendix G inf-sup operator is not a separately defined Lean object either. Keep those limits explicit.
